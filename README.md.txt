Dental Appointment Management System

Description
The Dental Appointment Management System is a web-based platform designed to automate and modernize the scheduling process for dental clinics. By replacing manual appointment books with a digital solution, the system reduces scheduling conflicts and administrative errors.
It features a user-friendly portal for patients to book and track appointments online, alongside a comprehensive dashboard for dentists and staff to manage schedules, patient records, and daily operations. The system prioritizes data privacy and security using a hybrid Role-Based (RBAC) and Attribute-Based (ABAC) access control model.

Key Features
Patient Module: Online registration, profile management, and real-time appointment booking.
Admin/Dentist Module: Manage working hours, approve/reschedule appointments, and track patient visit history.
Secure Access: Multi-layered security using RBAC (for roles) and ABAC (for specific data attributes).
Reporting: Automated generation of daily/weekly appointment summaries and patient statistics.
Notifications: Automated reminders to reduce no-show rates.
